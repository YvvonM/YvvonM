Rather than listing all my repositories, here is a curated selection of systems representing my engineering depth, with a focus on agent evaluation, low-latency tools, and autonomous systems:

### 🧠 Advanced Agent Evaluation & Autonomous Pipelines

#### 💜 **[YvvonM/purple_agent_pibench](https://github.com/YvvonM/purple_agent_pibench)**
A production-ready, multi-agent benchmark framework designed for regulatory compliance and financial risk intelligence.
*   **Orchestration Engine:** Implements a stateful 4-agent setup (Manager, Policy, Data, Conversation) with dynamic task routing, asynchronous execution, and centralized SQLite session state memory.
*   **FINRA Hybrid RAG:** Integrates semantic search (BGE embeddings + ChromaDB) with sparse keyword retrieval (BM25), cross-encoder reranking, and a Neo4j Graph database for deep policy/relationship queries. Hosted as an MCP server.
*   **Text-to-SQL Agent:** Features a secure schema-aware natural language to SQL compiler with integrated safety layers (SELECT-only queries), schema retrieval via RAG, and an automated key rotation system to prevent LLM rate limiting.

#### 🔬 **[YvvonM/Research_Agent](https://github.com/YvvonM/Research_Agent)**
An autonomous research pipeline that coordinates multiple agents to generate research directions, execute parallel deep dives, and compile structured knowledge outputs directly to SQLite.

#### 🛠️ **[YvvonM/raptorreview-ai](https://github.com/YvvonM/raptorreview-ai)**
An automated AI pull request reviewer utilizing Groq's APIs to conduct context-aware code review.
